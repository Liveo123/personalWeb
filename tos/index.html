New-computer recovery

1. Download/sync the full portable folder. 2. Open OPEN TOS.cmd on Windows or TOS GUI.html. 3. Load the TOS folder. 4. Import exported GUI settings if wanted. 5. Generate a fresh handoff for the LLM you choose.
